# Cyberdeck wallpapers

All five images are original procedural output of `../kit/gen_walls.py`
(numpy + Pillow, seeded; no third-party art). Released with the shell.
Text on them uses Share Tech Mono (SIL OFL 1.1, `../fonts/ShareTechMono-OFL.txt`).

| File | Scene | Register |
|---|---|---|
| `netrunner.png` | rain-soaked neon alley | Netrunner |
| `megacorp.png` | corporate monolith | Megacorp |
| `deck.png` | wireframe terrain | Deck |
| `orbital.png` | orbital station | extra |
| `circuit.png` | circuit board | extra |
